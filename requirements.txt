# ============================
# How to Run the Project
# ============================

# 1. Install Node.js (>= v18)
#    https://nodejs.org/



# 2. Backend Setup
#    cd backend
#    npm install
#    npm start

# 3. Frontend Setup
#    cd frontend
#    npm install
#    npm start

# 4. Open in browser:
#    http://localhost:3000  (Frontend)
#    http://localhost:5000  (Backend API)
