# 🏠 Real Estate Web Application

A full-stack real estate web application where users can browse, filter, and view detailed property listings, and contact agents directly through the platform.

---

## 📌 Features
- Property listing with images and details.
- Advanced search and filtering by location, price, and keywords.
- Detailed property view with image carousel.
- Contact agent functionality via form (email integration).
- Scroll-to-top for better navigation.
- Fully responsive UI for desktop and mobile.

---

## 🎯 Objectives
- Provide a centralized platform for real estate property browsing.
- Improve user experience with search, filter, and detail view.
- Enable seamless communication between buyers and agents.

---

## 🛠 Tech Stack
**Frontend**
- React.js  
- Bootstrap / Tailwind CSS  
- React Router  

**Backend**
- Node.js  
- Express.js  

**Database**
- MongoDB  

**Other Tools**
- Nodemailer (for email notifications)  
- Axios (API calls)  

---

## 🔄 Application Flow
1. User visits the homepage and views available properties.  
2. Applies filters (location, price, keywords) to narrow search.  
3. Selects **"View More"** for detailed property view.  
4. Navigates images using carousel.  
5. Sends inquiry through **Contact Agent** button.  
6. Agent receives inquiry via email.
